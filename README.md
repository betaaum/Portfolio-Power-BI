# 📊 Portfólio — Business Intelligence

Projetos desenvolvidos para aplicação prática de conhecimentos em
Business Intelligence, com foco em Power BI, análise de dados,
modelagem dimensional e tomada de decisão.

---

## 🛠️ Competências demonstradas

- Modelagem dimensional
- Modelo estrela
- Power Query
- DAX
- Criação de KPIs
- Análise de dados
- Visualização de dados
- Storytelling
- UX de dashboards
- Análise orientada ao negócio

---

> Os projetos identificados como fictícios utilizam dados simulados
> e foram desenvolvidos para fins de estudo e demonstração de
> conhecimentos em Business Intelligence.
